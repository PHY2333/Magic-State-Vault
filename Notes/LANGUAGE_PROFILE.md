# Notes/LANGUAGE_PROFILE.md

本文件规定正式 Notes 的默认中文教材语体。来源原文、代码和约定名称可按任务另行覆盖。

## 1. 基本语体

- 主语言：简体中文。
- 语气：准确、连续、解释性；避免词典条目、审查报告和中英混合速记。
- 句子优先说明具体对象、关系和动作，不用流程词替代数学内容。
- 第一句优先建立一个稳定对象，不同时处理术语多义、历史、边界和下游用途。

## 2. 英文与缩写

- 公认缩写可保留：CSS、HGP、qLDPC、LP、POVM 等。
- 首次出现时优先写“中文术语（英文全称，缩写）”；后文使用中文术语或缩写。
- 不在中文正文反复混用 `check matrix`、`row pair`、`support space` 等英文短语。
- 来源原句、代码标识和必须保持的作者术语除外。

## 4. 定义语句

避免循环或空泛表达：

```text
X 是用于记录 X 关系的对象。
X 是一种做 X 的方法。
```

合格的局部定义至少提供以下两项：

- 类别：它属于什么对象；
- 数据：由什么组成；
- 作用：当前怎样使用；
- 区分：它与相邻对象的差别。

例如“奇偶校验矩阵”的局部提醒可写成：

> 每一行规定一条模 2 的奇偶校验条件。

而不是“用于记录校验关系的矩阵”。

## 5. 标题

- 标题使用对象短语、问题短语或构造短语；
- 不使用审查结论或完整计划句；
- guided 正文中，问题标题必须是读者已经能够理解的问题。

## 6. 自然度检查

清稿时检查：

- 是否出现“既指 A，也指 B”的词典式首句，而当前并不需要讨论多义性；
- 是否按内部 checklist 一项一句机械展开；
- 是否中英混合到影响连续阅读；
- 是否为了避免重复而使用空泛替代词；
- 是否有句子虽正确，却没有给读者可继续使用的理解。
