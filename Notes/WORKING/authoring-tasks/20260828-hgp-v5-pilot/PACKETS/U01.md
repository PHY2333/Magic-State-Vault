# Required mathematics and examples

本 unit 只需以下四项事实，全部已在 packet 内闭合：

1. 经典二进制奇偶校验矩阵的每一行规定一条模 2 的奇偶校验条件。
2. 超图乘积构造以两张这类矩阵为输入，所得量子码称为 HGP 码。
3. 在本构造中把两份经典输入记为 A、B，把两张量子校验输出记为 H_X、H_Z。
4. H_X、H_Z 的列对应同一组物理量子比特；一行中为 1 的列指出校验作用的位置，这些位置构成该行的支撑；两矩阵的行分别给出 X 型、Z 型校验的支撑。这里的 CSS 要求两类校验彼此对易。

不需要例子或计算。尤其不写 Pauli 交换、\(H_XH_Z^T=0\)、链复形或具体 HGP blocks。
