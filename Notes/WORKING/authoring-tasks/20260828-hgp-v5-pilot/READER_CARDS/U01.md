# Reading situation

第一次进入 HGP 笔记的开头，需要先认清正文正在介绍哪些对象，以及这一开头将留下什么问题。

# Assumed entry capabilities

- 见过 CSS 这一名称。

# Explicitly not assumed

- 不假设知道超图乘积构造属于什么类别。
- 不假设知道 HGP 码与该构造之间的关系。
- 不假设知道 A、B 与 H_X、H_Z 在当前构造中的不同角色。
- 不假设知道矩阵的行、列和支撑在当前 CSS 语境中的用途。
- 不假设知道两类量子校验需要满足的关系或其保证机制。

# Expected exit capability

能够区分开头涉及的方法、所得对象、两组矩阵角色，并准确说出正文接下来需要回答的核心问题。

# Language register

自然、连续的简体中文教材语体；HGP、CSS 与数学符号之外不使用不必要的英文。开头应像教材进入一个对象，而不是词典条目、维护说明或链接清单。
