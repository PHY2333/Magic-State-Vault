# Reading situation

读者刚读完 HGP 开头的对象与输入／输出区分，正在追问两类量子校验为什么还需要满足额外的相容要求，以及随后出现的整体映射图景究竟说明什么。

# Assumed entry capabilities

- 能区分超图乘积构造与由它得到的 HGP 码。
- 知道 `A,B` 是经典输入，`H_X,H_Z` 是量子校验输出。
- 知道两张输出矩阵的列对应同一组物理量子比特，行分别给出 X 型与 Z 型校验的支撑。
- 知道当前 CSS 问题要求两类校验彼此对易。

# Explicitly not assumed

- 不假设读者会把二进制行翻译成逐位置的泡利算符作用。
- 不假设读者知道同一量子比特和不同量子比特上的交换理由。
- 不假设读者能从局部交换规则得到整条校验的对易判据。
- 不假设读者会从矩阵元素读取支撑重叠，或理解三个坐标空间与两支映射在当前问题中的用途。
- 不假设读者能完成完整的泡利矩阵逐项计算。

# Expected exit capability

读者能够用自己的话说明：逐位置交换规则怎样决定两类校验能否对易，怎样把所有校验对的要求汇总成一个矩阵条件，以及三个坐标空间和两支映射为何能统一表达这个条件。读者还应能指出，下一步尚需解决的是怎样从两份经典输入得到满足要求的具体构造。

# Language register

使用自然、连续的简体中文教材语体。HGP、CSS 和必要数学符号可以保留；其余概念优先使用统一中文术语。正文应让 HGP 的当前问题始终清楚可见，不使用维护或审查语言。
