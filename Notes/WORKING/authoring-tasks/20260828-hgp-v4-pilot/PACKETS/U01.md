# Phase sequence

## P1 — 稳定对象与所得码

1. 第一完整句只以“超图乘积构造”为稳定主语。
2. 在同一句中按以下语义次序闭合：两张经典二进制奇偶校验矩阵 → 这类矩阵每一行规定一条模 2 条件 → 该构造由此得到 CSS 量子码。
3. 紧接的第二句说明“由这种构造得到的量子码称为 HGP 码”。
4. 可以再用一个短句区分方法与所得对象，但不得使用“既指……也指……”句式。

P1 不出现 `A,B,H_X,H_Z`、链接、链复形或下游工具。

## P2 — 输入与输出

1. 把两张种子矩阵记为 `A,B`，完整引入它们在 HGP 中的输入角色。
2. 把构造给出的量子校验矩阵记为 `H_X,H_Z`，明确它们是输出，不是 `A,B` 的别名。
3. 用自然中文复述一次输入／输出关系；不写尺寸、块公式或流程元语言。

## P3 — CSS 的当前局部要求

1. `H_X,H_Z` 的列对应同一组物理量子比特。
2. `H_X` 的每一行给出一条 X 型校验的支撑，`H_Z` 的每一行给出一条 Z 型校验的支撑。
3. CSS 在这里仅表示：这两类校验作用在同一组物理量子比特上，并且必须彼此对易。
4. 不在本 unit 解释对易机制，也不提前断言任意矩阵 pair 一定失败。
5. 最后一句必须只问：“怎样由构造本身保证两类校验彼此对易？”
