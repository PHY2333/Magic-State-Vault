# Reading situation

第一次连续阅读 HGP reference 的开头，尚未进入具体矩阵公式。

# Assumed entry capabilities

- 见过 CSS 这个名称。
- 能跟随一句关于二进制矩阵行的局部提醒。

# Explicitly not assumed

- 不假设知道 HGP 构造的类别或构造与所得码的关系。
- 不假设知道两张经典矩阵和两张量子校验矩阵在当前构造中的不同角色。
- 不假设知道 CSS 在当前段落中的具体含义或对易机制。

# Expected exit capability

能清楚区分当前出现的方法、所得对象、输入和输出，并指出下一步需要解决的合法性问题。

# Language register

自然、连续的简体中文教材语体；HGP、CSS 与数学符号之外不使用不必要英文。
