# Reading situation

已经读完 HGP 开头的对象和输入／输出区分，正在追问两类输出校验怎样满足所需的对易关系。

# Assumed entry capabilities

- 能把两张输出矩阵的共享列读成同一组物理量子比特。
- 能把矩阵的一行读成一条相应类型校验的支撑。
- 知道经典种子输入与量子校验输出不是同一角色。

# Explicitly not assumed

- 不假设能从一行的支撑读出整条校验算符的逐位置作用。
- 不假设局部交换规则怎样决定整条校验的交换结果。
- 不假设怎样从矩阵乘法读取支撑重叠，或三项箭头在当前问题中的用途。
- 见过相关结构的名称不等于知道其含义。

# Expected exit capability

能从局部规则重建全部异型校验的矩阵条件，并能说明三项箭头中的对象、映射和连续复合怎样服务当前问题。

# Language register

自然、连续的简体中文教材语体；HGP、CSS 与数学符号之外不使用不必要英文。
