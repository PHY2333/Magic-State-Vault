# Contract Audit

## 审计结论

Revision 3 通过。U01 与 U02 的数学、来源边界、phase 顺序、定义时机、claim closure、出口能力和语言约束均与各自 packet 一致；没有需要退回 Mapper、Design、Writer 或用户处理的 finding。

## Revision 3 专项检查

### U02 开头

- 开头先回接“怎样保证对易”，随即把当前任务限定为把输出必须满足的要求化成可检验的矩阵条件，并把注意力落到一条 X 型行与一条 Z 型行；这符合 opening contract。
- “当前先”明确表示本 unit 先建立判据，不表示已经展示 HGP 的具体输出，也不预先承诺这些输出已经满足判据。
- 开头没有出现三项箭头、链复形名称、具体 HGP blocks、种子矩阵尺寸或其它禁止主题。

### U02 结尾

- 末段把本 unit 的所得明确限定为判据及“连续复合为零”的写法，并明确排除“尚未代入的具体输出已经通过”的读法。
- 对后续工作的陈述是条件式：先由 (A,B) 得到具体的 (H_X,H_Z)，再核验 (H_XH_Z^T=0)；只有核验成立，才可得出构造保证对易的结论。正文没有声称核验必然成功，也没有代替后续推导作保证。
- 该过渡只复用 U01 已建立的输入／输出角色，没有给出或预告 Kronecker blocks、(A/B) 尺寸、两路径抵消或其它 forbidden topics；它仍属于 P2 的收束，而没有形成第三个教学 phase。
- 结尾回到 CSS 对易与零复合的统一表达，符合 transition contract。

## Packet compliance

- Phase sequence：U01 严格按 P1→P2→P3；U02 只有两个教学标题，P1 七步顺序完整，三项箭头和“链复形”均在 P2 才出现。
- Definition cards：超图乘积构造、HGP 码、奇偶校验矩阵、CSS 当前含义、行到算符表示和链复形均有类别／数据／当前作用／相邻对象区分所需的闭合信息；没有循环定义或未授权专名。
- Notation/load budget：U01 未超出允许记号；U02 的符号按局部算符→总符号→矩阵元→零矩阵→三项箭头的顺序引入，并在每一步后用中文解释。
- Required mathematics：同比特矩阵乘法、异比特两种张量积次序、总符号、矩阵元、([1]) 反例以及两个映射的逐项作用均实际执行，没有以“显然”或模型常识代替 premise。
- Link policy：两个 draft 均无 wikilink，删除链接条件平凡满足。
- Forbidden topics：未出现 Kronecker blocks、(A/B) 尺寸、total degree、两路径抵消、homology、Künneth、stabilizer group、logical quotient、syndrome、metacheck 或仓库流程说明；U02-P1 未出现 (C_2,C_1,C_0) 或“链复形”。
- Language contract：正文保持连续简体中文教材语体；HGP、CSS 和数学符号属于允许例外，没有用英文速记替代既定中文术语。
