- 读者第一次接触 HGP 的类别、输入和输出。
- 读者只见过 CSS、X-type check、Z-type check 这些名称，不假设能解释或操作。
- 不假设读者会 check-matrix 行列、矩阵对易判据、Kronecker、chain/cochain 或二进制抵消。

# Exit capability

本单元结束后，读者能够：

- 说明 HGP 是从两张经典二进制校验矩阵构造 CSS 量子码的方法或由此得到的一类码；
- 区分输入 \(A,B\) 与输出 \(H_X,H_Z\)；
- 说明输出的两矩阵分别收集 X-type 与 Z-type checks；
- 提出“怎样由构造本身保证两组 checks 对易”这一问题。

# Phase sequence

## P1 — 类别与第一句术语闭包

1. 第一句只完成这项工作：说明 HGP 是从两张经典二进制校验矩阵构造 CSS 量子码的方法或由此得到的一类码。
2. 紧接着把“经典二进制校验矩阵”解释为由 0/1 组成、记录经典校验关系的矩阵；不讲行列角色。
3. 再把 CSS 在当前所需深度解释为：两组作用在同一批物理量子比特上的 X-type 与 Z-type checks，并且它们需要彼此对易。
4. 本 phase 不使用数学符号。

## P2 — 输入／输出对照

1. 把两张经典输入依次记为 \(A,B\)。
2. 把构造输出依次记为 \(H_X,H_Z\)。
3. 明确 \(H_X\) 收集 X-type checks，\(H_Z\) 收集 Z-type checks；二者作用在同一批物理量子比特上。
4. 用一句短对照释放负荷：输入是 \(A,B\)，输出是 \(H_X,H_Z\)。

## P3 — 只提出自动对易问题

1. 指出构造的任务不只是产生两张输出矩阵；两类 checks 还必须彼此对易。
2. 指出任意写下两张矩阵不能自动给出这项保证。
3. 以问题结束：怎样由构造本身保证两组 checks 对易？
4. 不回答问题，不出现矩阵乘积或三项箭头。
