# Reader entry capabilities

前一单元已经保证读者能够：

- 说明 HGP 是从两张经典二进制校验矩阵构造 CSS 量子码的方法；
- 区分输入 \(A,B\) 与输出 \(H_X,H_Z\)；
- 把 \(H_X,H_Z\) 分别读成 X-type 与 Z-type check matrices；
- 知道两矩阵作用在同一批物理量子比特上，并提出构造怎样保证 checks 对易的问题。

不假设读者会把矩阵行、共享列、矩阵乘积、二进制 overlap 或 chain complex 用于当前问题。

# Exit capability

本单元结束后，读者能够：

- 说明 \(H_X,H_Z\) 的共享列与每行 check 的含义；
- 解释 \(H_XH_Z^T\) 的一个元素怎样记录一个异型 row pair 的 overlap parity；
- 说明 \(H_XH_Z^T=0\) 为什么等价于所有异型 checks 对易；
- 说明任意矩阵 pair 不保证该条件；
- 用
  \[
  C_2\xrightarrow{H_Z^T}C_1\xrightarrow{H_X}C_0
  \]
  解释连续两步为零如何结构性承接自动对易，并在解释完成后识别“链复形”名称。

# Preceding transition

前一 staged unit 保证以这项问题结束：

> 怎样由构造本身保证两组 checks 对易？

本单元直接回答该问题，不重复 HGP 类别或输入／输出介绍。

# Phase sequence

## P1 — 先建立对易问题

严格按下列微顺序写作：

1. \(H_X,H_Z\) 的列使用同一批物理量子比特坐标。
2. 每一行用 0/1 标出一条相应类型 check 作用的位置。
3. 取一条 X-type row 和一条 Z-type row；\(H_XH_Z^T\) 中对应元素把两行共同为 1 的列数按模 2 记录。
4. 该元素为 0，表示共同作用位置是偶数个。
5. 每个共同位置带来一次 X/Z 符号反转；偶数次反转成对抵消，因此这对 checks 对易。
6. \(H_XH_Z^T=0\) 要求每个元素都为零，所以同时覆盖所有异型 row pairs。
7. 任意写下两张共享列的矩阵不能保证乘积为零。

Consolidation：

- 在步骤 3 后用一句话确认“一个矩阵元素只检查一对 rows”。
- 在步骤 6 后用一句话确认“全零矩阵同时保证所有 row pairs 对易”。

Hard boundary：

- 本 phase 不出现 \(A,B\) 的尺寸。
- 本 phase 不出现 \(C_2,C_1,C_0\)、箭头或 chain complex 名称。
- 不出现 product blocks 或其它构造细节。

## P2 — 再给三项箭头整体

严格按下列顺序写作：

1. 展示
   \[
   C_2\xrightarrow{H_Z^T}C_1\xrightarrow{H_X}C_0.
   \]
2. 只把 \(C_1\) 解释为物理量子比特 support 空间。
3. 左侧 \(C_2\) 承载 Z-type checks 的二进制组合；\(H_Z^T\) 把这种组合写成 \(C_1\) 中的物理 support。
4. 右侧 \(C_0\) 承载对 X-type checks 的 overlap 结果；\(H_X\) 从 \(C_1\) 读出这些结果。
5. 连续两步的复合就是 \(H_XH_Z^T\)，所以“连续两步为零”就是 P1 的 CSS 对易条件。
6. 只有在上述对象、箭头角色和用途全部解释后，才允许写：“这种相邻线性映射复合为零的三项结构称为链复形。”
7. 回到 HGP：只说明下一步才会处理两张经典输入怎样具体生成这三个位置与两支箭头；本 draft 不给生成公式。

Hard boundary：

- 不出现 Kronecker blocks、输入矩阵的线性映射尺寸、total-degree 公式、两路径抵消、homology 或 cochain 迁移。
- 不设计、命名或概述新的学习单元。
