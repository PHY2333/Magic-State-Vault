超图积码（HGP 码）既指一种从两张经典二进制校验矩阵构造 CSS 量子码的方法，也指由这种方法得到的一类码。经典二进制校验矩阵是由零和一组成、用于记录经典校验关系的矩阵。CSS 在这里表示：同一批物理量子比特上有 X-type 与 Z-type 两组 checks，并且这两组 checks 必须彼此对易。

两张经典输入依次记为 \(A,B\)，构造的两张输出依次记为 \(H_X,H_Z\)。其中，\(H_X\) 收集 X-type checks，\(H_Z\) 收集 Z-type checks，二者作用在同一批物理量子比特上。简言之，输入是 \(A,B\)，输出是 \(H_X,H_Z\)。

构造的任务不只是产生两张输出矩阵；两类 checks 还必须彼此对易。任意写下两张矩阵并不能自动给出这项保证。那么，怎样由构造本身保证两组 checks 对易？
