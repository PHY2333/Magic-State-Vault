# 逐对检查两类 checks 是否对易

要由构造本身保证两组 checks 对易，首先要看清两张 check matrices 怎样描述同一批物理量子比特。\(H_X\) 与 \(H_Z\) 的列使用相同的物理量子比特坐标；每一行则用 0 和 1 标出一条相应类型的 check 作用在哪些位置，值为 1 的列就是这条 check 的 support。

取 \(H_X\) 的一条 X-type row 和 \(H_Z\) 的一条 Z-type row。\(H_XH_Z^T\) 中与这两行对应的元素，等于两行共同为 1 的列数按模 2 计算后的结果。换句话说，一个矩阵元素只检查这一对 rows。如果该元素为 0，共同作用的位置便有偶数个；在每个共同位置交换 X 与 Z 都会带来一次符号反转，而偶数次符号反转会成对抵消，所以这对 checks 对易。

条件
\[
H_XH_Z^T=0
\]
要求乘积的每个元素都为零，也就要求每一对 X-type row 与 Z-type row 都具有偶数 overlap。因此，全零矩阵同时保证所有异型 row pairs 对易。反过来，仅仅任意写下两张共享同一组列的矩阵，并不会迫使这些逐对 overlap 都是偶数，也就不能自动保证乘积为零。

# 用三项箭头统一表达对易条件

同一条件可以整体写成三项箭头：
\[
C_2\xrightarrow{H_Z^T}C_1\xrightarrow{H_X}C_0.
\]
中间的 \(C_1\) 是物理量子比特的 support 空间。左侧的 \(C_2\) 承载 Z-type checks 的二进制组合，\(H_Z^T\) 把这样的组合写成 \(C_1\) 中的物理 support；右侧的 \(C_0\) 承载对 X-type checks 的 overlap 结果，\(H_X\) 从一个物理 support 读出这些结果。

沿两支箭头连续走两步，所得复合正是 \(H_XH_Z^T\)。因此，要求连续两步为零，就是要求每个 Z-type check 的 support 与所有 X-type checks 都有偶数 overlap；这与前面的 CSS 对易条件是同一个条件。这里的箭头图并没有另加一条对易规则，而是把所有逐对条件统一表达为一个零复合条件。

这种相邻线性映射复合为零的三项结构称为链复形。对 HGP 而言，接下来还需要说明两张经典输入怎样具体生成这三个位置与两支箭头；这里暂不写出生成公式。
