# Translations/TRANSLATION_GUIDE.md

本文件规定 paper、book 等来源的全文翻译、局部摘译、进度记录、截图归属和译文验收。文献管理任务先读取 `Papers/PAPER_MANAGEMENT.md`；稳定文献 ID、原文件和精确版本以其入口指向的 `Papers/SOURCES.md` 当前登记为准，主辅关系以 `Papers/RELATIONS.md` 为准。

译文是原始来源的中文阅读入口，不是知识笔记，也不能替代原始来源作为最终引用依据。从译文建立概念笔记、论文导读或继续推导时，执行 `Notes/WORKFLOWS/note-writing.md`。

---

## 1. 翻译类型与边界

### 1.1 全文翻译

全文翻译按一个明确原文版本和原文顺序覆盖标题、摘要、正文、脚注、图表说明、附录和致谢。公式、编号、引文和参考文献条目必须保留；参考文献表可以保留原文格式，但不得无说明地省略。

“全文翻译”默认指完整翻译 `Papers/SOURCES.md` 为该来源登记的一个具体原文件，不自动包含单独存在的 supplementary material、ancillary files、网页附加内容或其他版本。需要翻译这些附加材料时，必须在“覆盖范围”中逐项列明。

只有同时满足以下条件时才创建全文译本：

- 用户明确要求全文翻译；
- `Papers/SOURCES.md` 的当前来源登记中，“翻译计划”已标记为“全文翻译”。

不得因为文献已经入库就自动全文翻译。

### 1.2 局部摘译

局部摘译只翻译明确列出的章节、印刷页码、PDF 页序或段落。每个片段必须标出原文定位；所有非连续位置必须使用“省略说明”callout。摘要或转述不得标成摘译。

### 1.3 知识笔记

知识笔记可以重组、比较、解释或继续推导，应保存到 `Notes/` 并执行笔记写作流程。以下内容不得无标识地混入译文：

- 其他来源的解释或结论；
- 为适配本库而重排的论证；
- 原文没有给出的例子或推导；
- 对作者结论的评价。

必要补充、未决内容和省略位置只使用以下固定格式：

```md
> [!note] 译注
> 补充内容。
```

```md
> [!warning] 待核对
> 尚不能可靠确认的内容。
```

```md
> [!abstract] 省略说明
> 原文第 12 至 17 页未译，下一段从 Section 4 开始。
```

正文中不得使用没有固定格式的“译者注”“待确认”“此处省略”等变体。无法可靠确定的内容不得猜测补全；局部摘译的所有非连续位置必须使用“省略说明”。

## 2. 文件与目录

翻译文件使用 `Papers/SOURCES.md` 当前登记的稳定文献 ID：

```text
Translations/
├── TRANSLATION_GUIDE.md
├── <文献ID>.full.zh-CN.md
├── <文献ID>.excerpt.zh-CN.md
└── Snapshots/
    └── <文献ID>/
        └── p<印刷页码>-<两位序号>-<简述>.png
            或 pdfp<PDF页序>-<两位序号>-<简述>.png
```

- 每个文献 ID 至多维护一个当前全文译本和一个当前局部摘译文件。
- 局部摘译统一收在一个 `.excerpt.zh-CN.md` 文件中，不为每个片段创建小文件。
- 局部摘译扩展为全文译本时，应合并已译内容并消除重复；不得长期保留相互冲突的两套译文。
- 目录大小写固定为 `Translations/Snapshots/`，不得使用 `translations/`、`snapshots/` 等变体。
- 辅助文献拥有独立的译文和截图目录。即使 S002 用于辅助 S003，S002 的截图也必须放入 `Translations/Snapshots/S002/`。

译文文件与来源登记使用三个相互独立的概念：

```md
- 翻译计划：无 / 局部摘译 / 全文翻译
- 当前全文译本：无 / [[对应译文]]
- 局部摘译：无 / [[对应摘译]]
```

- “翻译计划”只表示是否计划翻译以及计划范围，不表示译文进度，也不承担文件链接。
- 全文译本创建、删除或路径变化时，更新“当前全文译本”链接。
- 局部摘译创建、删除或路径变化时，更新“局部摘译”链接。
- 译文的翻译进度和核对状态只在译文文件内部维护，不在来源登记中重复维护。

译文必须在“译文信息”中绑定具体原文版本。若来源更新为新版本，不得静默把旧译文声明为适用于新版本；应先核对版本差异，再更新当前译文、原文版本字段、覆盖范围和待核对项。只有用户明确要求保留旧译本时，才另行决定保存方式；本指南不建立默认的多版本译文并存体系。

## 3. 译文信息与进度

每个译文开头使用：

```md
## 译文信息

- 文献 ID：
- 原文：[原文文件](../Papers/<实际文件名>)
- 原文版本：
- 翻译类型：全文翻译 / 局部摘译
- 覆盖范围：
- 印刷页码：有 / 无；范围或说明：
- PDF 页序：从 1 开始
- 页码对应关系：
- 状态：翻译中 / 初译完成 / 待核对 / 已核对
- 待核对项：无 / 具体列表
```

整个译本的状态含义固定为：

- 翻译中：目标覆盖范围尚未全部完成。
- 初译完成：覆盖范围已经完成，但尚未完成系统核对。
- 待核对：已进行检查，但仍存在明确的待核对项。
- 已核对：覆盖、术语、公式编号、交叉引用、图片来源和链接检查均已通过。

全文翻译进行中时增加按原文章节划分的进度表：

```md
| 原文章节 | 印刷页码 | PDF 页序 | 状态 | 待核对 |
|---|---:|---:|---|---|
| Abstract | 1 | 4 | 已核对 | 无 |
```

进度表中的单个章节只使用“待译 / 已译 / 已核对”，不得与整个译本的四种状态混用。存在未列明缺页、未处理图表、失效交叉引用或“待核对”时，不得把整个译本标成“已核对”。

对于术语密集、篇幅较长或分阶段完成的译文，应在“译文信息”之后维护“术语表”；短篇且术语简单时可以省略。例如：

```md
## 术语表

| 原文 | 统一译名 | 说明 |
|---|---|---|
| balanced product | 平衡积 | 不译为“均衡乘积” |
| coinvariants | 余不变量 | |
| augmentation map | 增广映射 | |
```

术语表只用于保证同一译本内部一致，不得借此把作者记号替换成本库记号，也不得加入知识笔记式的长篇解释。来源登记只按第 2 节同步翻译计划和译文链接；译文状态、章节进度和待核对项只在译文文件内部维护。

## 4. 翻译规则

- 按原文章节和段落顺序翻译，不重组作者的论证路径。
- 保留标题层级、定义、定理、引理、证明、公式、图表、脚注和附录的原编号。
- 数学变量、公式和作者定义的记号保持不变；不要静默改成 `CANONICAL_KNOWLEDGE.md` 中的固定记号。确需说明对应关系时使用第 1.3 节规定的 `[!note] 译注` callout。
- 术语首次出现时给出中文译名和原文，后续保持一致。一个术语需要改译时，应检查并统一整个译本。
- 交叉引用必须能对应到译文中的编号；尚未翻译到的目标可以暂时使用 `[!warning] 待核对` callout，完成全文时必须消除。
- 图注、表题、表内文字和正文对图表的说明属于译文，不能仅用截图代替。
- 引文编号和参考文献键保持与原文一致。译文不得把译文自身当作论文、定理或数据的最终出处。
- 原文疑似存在笔误时保留原文含义，并使用 `[!note] 译注` callout 说明，不得静默修正。

## 5. 截图

截图只用于保留难以可靠转写的视觉信息，例如：

- 原文图形、线路图或示意图；
- 复杂表格；
- 版式本身承载含义的多行公式；
- OCR 无法可靠恢复的局部内容。

可正常翻译的正文段落不得用截图替代。截图应裁取足以保留上下文的最小完整区域，并在译文附近写明印刷页码、PDF 页序、图号或表号。

- 公式原则上必须转写为可编辑的 LaTeX，并保留原文编号。即使保留原文公式截图，截图也只能作为排版或辨认依据，不能替代公式文本和编号。
- 表格能够可靠转写时，应优先转写为 Markdown、HTML 或其他可编辑格式。表格截图用于保存原版式，不应默认替代表格内容的转写。

命名规则：

```text
p021-01-fig-3-balanced-product.png
pdfp024-02-unnumbered-diagram.png
```

- 优先使用原文印刷页码 `p021`。
- 无印刷页码或印刷页码不明确时使用 PDF 页序 `pdfp024`。
- PDF 页序一律从 1 开始。
- 两位序号用于区分同一页的多个截图。
- 简述使用短横线连接，不使用无意义名称如 `image1.png`。

从位于 `Translations/` 根目录的译文引用：

```md
![原文图 3：balanced-product 构造，印刷页码 21](Snapshots/S003/p021-01-fig-3-balanced-product.png)
```

翻译某文献时只使用该文献自身的截图。若辅助文献中的图片用于综合解释，应进入相应知识笔记的 assets，而不是伪装成主文献原图。

## 6. 翻译流程

1. 先读取 `Papers/PAPER_MANAGEMENT.md`，再按照其中的入口读取 `Papers/SOURCES.md`；任务涉及主辅来源关系时，再读取 `Papers/RELATIONS.md`。稳定文献 ID、原文件和精确版本以 `SOURCES.md` 的当前登记为准，主辅关系以 `RELATIONS.md` 为准。
2. 确认“翻译计划”和本次任务是全文翻译还是局部摘译。创建全文译本前，必须同时满足用户明确要求全文翻译、来源登记中的“翻译计划”为“全文翻译”；随后创建对应文件，并填写译文信息、覆盖范围和初始状态。
3. 全文翻译先按原文目录建立章节骨架和进度表；局部摘译先列出所有目标印刷页码、PDF 页序或章节，并在非连续位置预留“省略说明”。
4. 按原文顺序翻译，维护术语一致性、公式编号、交叉引用和待核对项；需要术语表时同步维护。
5. 需要截图时按文献自身 ID 保存、命名和引用，同时翻译图注、表题及必要文字；公式和能够可靠转写的表格仍须保留可编辑文本。
6. 完成覆盖范围、术语、公式与编号、交叉引用、图片来源、链接和具体原文件边界检查。
7. 按第 7 节设置译文内部状态。全文译本创建、删除或路径变化时，在 `SOURCES.md` 更新“当前全文译本”链接；局部摘译创建、删除或路径变化时，更新“局部摘译”链接。不得把译文状态或章节进度同步到来源登记。

## 7. 验收

### 7.1 全文翻译

- `SOURCES.md` 指定的具体原文件内，标题、摘要、正文、脚注、图表说明、附录和致谢均有对应内容；额外材料只在“覆盖范围”逐项列明后纳入。
- 所有原文章节都出现在进度表中，印刷页码与从 1 开始的 PDF 页序均已记录，且没有未说明的跳段或缺页。
- 公式、定理、图表和交叉引用编号一致。
- 公式具有可编辑的 LaTeX 文本和编号；能够可靠转写的表格已有可编辑内容，截图没有替代这些文本。
- 术语在全文中一致；作者记号没有被静默替换。
- 术语密集、篇幅较长或分阶段完成的译文已经维护术语表。
- 所有截图都有文献 ID、所用的印刷页码或 PDF 页序、对应关系和图表定位。
- “译注”“待核对”和“省略说明”均使用固定 callout，没有与原文正文混淆。
- 参考文献表已翻译或明确说明保留原文格式。

### 7.2 局部摘译

- 每个片段都有章节、印刷页码、PDF 页序或段落定位。
- 所有非连续处都使用 `[!abstract] 省略说明` callout。
- 文件没有使用“全文翻译”或“已覆盖全文”等误导性表述。

整个译本按以下顺序设置状态，不得用单个章节的“已译”代替整体状态：覆盖范围尚未完成时为“翻译中”；覆盖范围已完成但尚未系统核对时为“初译完成”；已经检查但仍有明确问题时为“待核对”；所有必需检查通过后才标记为“已核对”。

## 8. 交付说明

翻译任务交付时说明：

- 文献 ID、原文文件和版本；
- 来源登记中的翻译计划、本次为全文翻译或局部摘译，以及实际覆盖范围；
- 译文状态和仍存在的待核对项；
- 新增或复用的截图目录和文件；
- 是否因文件创建、删除或路径变化，在 `Papers/SOURCES.md` 更新了“当前全文译本”或“局部摘译”链接；译文状态和章节进度不写入来源登记；
- 是否另外创建或修改知识笔记，以及是否执行笔记写作流程。
