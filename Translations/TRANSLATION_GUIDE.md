# Translations/TRANSLATION_GUIDE.md

本文件规定 paper、book 等来源的全文翻译、局部摘译、进度记录、截图归属和译文验收。文献 ID、原文件、版本和主辅关系以 `Papers/PAPER_MANAGEMENT.md` 为唯一管理入口；当前动态登记分别位于 `Papers/SOURCES.md` 和 `Papers/RELATIONS.md`。

译文是原始来源的中文阅读入口，不是知识笔记，也不能替代原始来源作为最终引用依据。从译文建立概念笔记、论文导读或继续推导时，执行 `Notes/WORKFLOWS/note-writing.md`。

---

## 1. 翻译类型与边界

### 1.1 全文翻译

全文翻译按一个明确原文版本和原文顺序覆盖标题、摘要、正文、脚注、图表说明、附录和致谢。公式、编号、引文和参考文献条目必须保留；参考文献表可以保留原文格式，但不得无说明地省略。

只有满足以下条件之一时才创建全文译本：

- 用户明确要求全文翻译；
- `Papers/PAPER_MANAGEMENT.md` 指向的来源登记中，该来源的“全文翻译”已标记为“计划”。

不得因为文献已经入库就自动全文翻译。

### 1.2 局部摘译

局部摘译只翻译明确列出的章节、页码或段落。每个片段必须标出原文定位；非连续片段之间明确写出“中间原文未译”。摘要或转述不得标成摘译。

### 1.3 知识笔记

知识笔记可以重组、比较、解释或继续推导，应保存到 `Notes/` 并执行笔记写作流程。以下内容不得无标识地混入译文：

- 其他来源的解释或结论；
- 为适配本库而重排的论证；
- 原文没有给出的例子或推导；
- 对作者结论的评价。

必要补充统一标为“译注”。无法可靠确定的内容标为“待核对”，不得猜测补全。

## 2. 文件与目录

翻译文件使用 `Papers/PAPER_MANAGEMENT.md` 登记的稳定文献 ID：

```text
Translations/
├── TRANSLATION_GUIDE.md
├── <文献ID>.full.zh-CN.md
├── <文献ID>.excerpt.zh-CN.md
└── Snapshots/
    └── <文献ID>/
        └── p<原文页码>-<两位序号>-<简述>.png
```

- 每个文献 ID 至多保留一个当前全文译本。
- 局部摘译统一收在一个 `.excerpt.zh-CN.md` 文件中，不为每个片段创建小文件。
- 局部摘译扩展为全文译本时，应合并已译内容并消除重复；不得长期保留相互冲突的两套译文。
- 目录大小写固定为 `Translations/Snapshots/`，不得使用 `translations/`、`snapshots/` 等变体。
- 辅助文献拥有独立的译文和截图目录。即使 S002 用于辅助 S003，S002 的截图也必须放入 `Translations/Snapshots/S002/`。

译文绑定具体原文版本。默认只保留一个当前译本，使用 `<文献ID>.full.zh-CN.md` 或 `<文献ID>.excerpt.zh-CN.md`，截图放入 `Snapshots/<文献ID>/`。

若同一文献 ID 的多个来源版本确需同时保留译文，使用 `Papers/PAPER_MANAGEMENT.md` 中登记的稳定短版本标识：

```text
Translations/<文献ID>.<版本>.full.zh-CN.md
Translations/<文献ID>.<版本>.excerpt.zh-CN.md
Translations/Snapshots/<文献ID>/<版本>/p<页码>-<序号>-<简述>.png
```

版本标识采用 `arxiv-v2`、`publisher` 等可稳定复用的短名称。`Papers/PAPER_MANAGEMENT.md` 指向的来源登记必须在“全文翻译”字段中明确链接当前译本。不得静默把旧译文标成适用于新版本，也不得让不同版本的截图共用可能冲突的文件名。

## 3. 译文信息与进度

每个译文开头使用：

```md
## 译文信息

- 文献 ID：
- 原文：[原文文件](../Papers/<实际文件名>)
- 原文版本：
- 翻译类型：全文翻译 / 局部摘译
- 覆盖范围：
- 页码基准：印刷页码 / PDF 页序
- 状态：翻译中 / 待核对 / 已核对
- 待核对项：无 / 具体列表
```

全文翻译进行中时增加按原文章节划分的进度表：

```md
| 原文章节 | 页码 | 状态 | 待核对 |
|---|---:|---|---|
| Abstract | 1 | 已译 / 待译 / 已核对 | 无 |
```

存在未列明缺页、未处理图表、失效交叉引用或“待核对”时，不得把整个译本标成“已核对”。若任务为全文翻译，完成或改变状态后通过 `Papers/PAPER_MANAGEMENT.md` 的入口更新当前来源登记中的“全文翻译”字段和路径；局部摘译只在自身文件中记录覆盖范围和状态，不更新该字段。

## 4. 翻译规则

- 按原文章节和段落顺序翻译，不重组作者的论证路径。
- 保留标题层级、定义、定理、引理、证明、公式、图表、脚注和附录的原编号。
- 数学变量、公式和作者定义的记号保持不变；不要静默改成 `CANONICAL_KNOWLEDGE.md` 中的固定记号。确需说明对应关系时使用“译注”。
- 术语首次出现时给出中文译名和原文，后续保持一致。一个术语需要改译时，应检查并统一整个译本。
- 交叉引用必须能对应到译文中的编号；尚未翻译到的目标可以暂时标“待核对”，完成全文时必须消除。
- 图注、表题、表内文字和正文对图表的说明属于译文，不能仅用截图代替。
- 引文编号和参考文献键保持与原文一致。译文不得把译文自身当作论文、定理或数据的最终出处。
- 原文疑似存在笔误时保留原文含义，并以“译注：原文疑似……”说明，不得静默修正。

---

## 5. 截图

截图只用于保留难以可靠转写的视觉信息，例如：

- 原文图形、线路图或示意图；
- 复杂表格；
- 版式本身承载含义的多行公式；
- OCR 无法可靠恢复的局部内容。

可正常翻译的正文段落不得用截图替代。截图应裁取足以保留上下文的最小完整区域，并在译文附近写明原文页码、图号或表号。

命名规则：

```text
p021-01-fig-3-balanced-product.png
pdfp024-02-unnumbered-diagram.png
```

- 优先使用原文印刷页码 `p021`。
- 无印刷页码或印刷页码不明确时使用 PDF 页序 `pdfp024`。
- 两位序号用于区分同一页的多个截图。
- 简述使用短横线连接，不使用无意义名称如 `image1.png`。

从位于 `Translations/` 根目录的译文引用：

```md
![原文图 3：balanced-product 构造，原文第 21 页](Snapshots/S003/p021-01-fig-3-balanced-product.png)
```

翻译某文献时只使用该文献自身的截图。若辅助文献中的图片用于综合解释，应进入相应知识笔记的 assets，而不是伪装成主文献原图。

## 6. 翻译流程

1. 读取 `Papers/PAPER_MANAGEMENT.md`，确认稳定文献 ID、原文件、精确版本和主辅关系。
2. 确认全文翻译或局部摘译，创建对应文件并填写译文信息、覆盖范围和初始状态。
3. 全文翻译先按原文目录建立章节骨架和进度表；局部摘译先列出所有目标页码或章节。
4. 按原文顺序翻译，维护术语一致性、公式编号、交叉引用和待核对项。
5. 需要截图时按文献自身 ID 保存、命名和引用，同时翻译图注、表题及必要文字。
6. 完成覆盖、术语、公式与编号、链接、截图来源和来源边界检查。
7. 验收通过后把译文标成“已核对”；若任务为全文翻译，通过 `Papers/PAPER_MANAGEMENT.md` 的入口同步更新当前来源登记，局部摘译不更新其“全文翻译”字段。

---

## 7. 验收

### 7.1 全文翻译

- 标题、摘要、正文、脚注、图表说明、附录和致谢均有对应内容。
- 所有原文章节都出现在进度表中，且没有未说明的跳段或缺页。
- 公式、定理、图表和交叉引用编号一致。
- 术语在全文中一致；作者记号没有被静默替换。
- 所有截图都有文献 ID、原文页码和图表定位。
- “译注”和“待核对”没有与原文正文混淆。
- 参考文献表已翻译或明确说明保留原文格式。

### 7.2 局部摘译

- 每个片段都有章节、页码或段落定位。
- 所有非连续处都明确标出“中间原文未译”。
- 文件没有使用“全文翻译”或“已覆盖全文”等误导性表述。

任一必需检查不通过时，状态保持“翻译中”或“待核对”，不得标记为“已核对”。

---

## 8. 交付说明

翻译任务交付时说明：

- 文献 ID、原文文件和版本；
- 全文翻译或局部摘译，以及实际覆盖范围；
- 译文状态和仍存在的待核对项；
- 新增或复用的截图目录和文件；
- 若为全文翻译，是否通过 `Papers/PAPER_MANAGEMENT.md` 的入口同步更新当前来源登记；局部摘译不更新其“全文翻译”字段；
- 是否另外创建或修改知识笔记，以及是否执行笔记写作流程。
